# BE-153 — Jalur baca timeline: sembunyikan update kosong dan kirim nama file lampiran

**Phase:** 5 · **Parent resmi:** T33 (timeline) · **Jenis:** PERUBAHAN KONTRAK (G24)
**Status implementasi:** PLANNED · **Hasil pengujian:** NOT RUN

## Tujuan dan sumber

`GET /nscmf/{record}/timeline` tidak mengirim `DRAFT_UPDATED`/`RESULT_UPDATED` yang tidak mengubah field apa pun, termasuk dalam hitungan paginasi. Endpoint ini juga menambahkan `attachment_filename` untuk kejadian lampiran. Audit tetap append-only; yang berubah hanya proyeksi baca.

Sumber: [12](../project_doc/12_API_Contract.md) §48; [07](../project_doc/07_UI_UX_Specification.md) §36; [11](../project_doc/11_ERD_Database_Schema.md) §34–35; [G24](06_GAP_DAN_KEPUTUSAN.md#g24).

## File dan batas antarmuka

- **Implementasi:**
  - `app/Repositories/Eloquent/Nscmf/EloquentRecordEvidenceRepository.php` (dan kontraknya);
  - `app/Services/Nscmf/RecordEvidenceService.php`.
- **Test:** `tests/Feature/Audit/EvidenceReadTest.php`.
- `valueAtLastReturnIfChanged` dan pembaca alasan pengembalian (`returnReason.ts`) tidak boleh berubah perilaku.

## Acceptance criteria

1. **AC-01:** Update Draft/Result tanpa perubahan tidak muncul, dan `total` tidak menghitungnya. Kejadian lain tanpa perubahan tetap muncul.
2. **AC-02:** `attachment_filename` berisi nama file dari audit untuk `ATTACHMENT_ADDED`/`ATTACHMENT_REMOVED`, dan `null` untuk kejadian lain.
3. **AC-03:** Baris audit di database tidak berubah.
