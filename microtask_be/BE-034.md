# BE-034 — Kredensial sementara sekali tampil

**Phase:** 2 · **Parent resmi:** T08 · **Jenis:** IMPLEMENTATION / RECONCILIATION
**Status implementasi:** PLANNED · **Hasil pengujian:** NOT RUN

## Tujuan dan sumber

Server generates random temporary password pada create/reset, hash-only persistence, must_change_password=true. Response transient no-store; jangan taruh plaintext di session/flash/DB/cache/Inertia history/log. Kehilangan response memerlukan reset baru, bukan retrieve.
