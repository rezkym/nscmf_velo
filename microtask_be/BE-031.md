# BE-031 — Current-password re-authentication

**Phase:** 2 · **Parent resmi:** T09 · **Jenis:** IMPLEMENTATION / RECONCILIATION
**Status implementasi:** IMPLEMENTED 2026-09-23 (menunggu human review) · **Hasil pengujian:** PASS (lihat handoff)

## Tujuan dan sumber

POST /account/re-authenticate current password menghasilkan proof server maksimal 15 menit. Proof terikat authenticated session; tidak silently extended dan tidak otomatis menjalankan ulang aksi sensitif.

Sumber: [10_Security_Rules.md](../project_doc/10_Security_Rules.md) §23–26; [12_API_Contract.md](../project_doc/12_API_Contract.md) §79; [16_Testing_Specification.md](../project_doc/16_Testing_Specification.md) §37–38; [19_Task_Implementation_Plan.md](../project_doc/19_Task_Implementation_Plan.md) §11.
