# BE-091 — Tetapkan batas 20 MB dalam byte secara tersinkronisasi

**Phase:** 6 · **Parent resmi:** T39, T59 · **Jenis:** DECISION / QUALIFICATION
**Status keputusan:** CLOSED 2026-09-23 · **Status implementasi:** IMPLEMENTED 2026-09-23 (menunggu human review) · **Hasil pengujian:** PASS lokal (tests/Feature/Attachment + tests/Integration/Malware dengan clamd asli)

## Tujuan dan sumber

G06: pemilik proyek menyetujui 2026-09-23 batas file attachment dan PDF validator 20,000,000 bytes inclusive (decimal 20 MB), dengan zero-byte ditolak dan chunk tetap 5 MiB = 5,242,880 bytes. Batas menghitung file bytes, bukan keseluruhan multipart HTTP request body; proxy/request-body limits tidak dipilih oleh keputusan ini.

Sumber: [06_Validation_Rules.md](../project_doc/06_Validation_Rules.md) §50; [10_Security_Rules.md](../project_doc/10_Security_Rules.md) §73; [11A_Resumable_Attachment_Upload_Synchronization.md](../project_doc/11A_Resumable_Attachment_Upload_Synchronization.md) §2, §3, §12, §25; [12_API_Contract.md](../project_doc/12_API_Contract.md) §51, §73; [19_Task_Implementation_Plan.md](../project_doc/19_Task_Implementation_Plan.md) §28.
