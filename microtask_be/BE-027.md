# BE-027 — Login dan logout username/password

**Phase:** 2 · **Parent resmi:** T06 · **Jenis:** IMPLEMENTATION / RECONCILIATION

## Tujuan dan sumber

GET /login, POST /login, POST /logout mengikuti session web/CSRF. Username/password, inactive denied, generic invalid credential, regenerate session dan server invalidation logout. Tidak ada registration/forgot password.
