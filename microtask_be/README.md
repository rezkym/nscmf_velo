# Microtask BE — NSCMF Implementation Plan

**Goal:** backlog backend lengkap, integrasi FE dan pembuktian perilaku nyata berdasarkan seluruh `project_doc`.
**Architecture:** Controller/Form Request → Service → Repository/Domain/Infrastructure contracts → adapter konkret. Service mengatur transaction, repository query/lock. Backend tetap authority.
**Stack:** Laravel 13/PHP 8.5, Vue/Inertia/TypeScript strict, MySQL 8.4; local-native utama, database session/cache/queue.

Paket berisi **149 microtask**, seluruh Phase 0–12, T00–T81, T05A/B/C, 14 slice T05, T18A–F, T19A–F, DG-01/DG-02. Ini dokumen pelaksanaan mendatang, bukan izin menjalankan seluruh backlog sekarang. **Status per task ada di tabel indeks.** Slice FE-01–30 sudah IMPLEMENTED/RECONCILED/DECIDED per 2026-09-23 dengan bukti di [handoff 2026-09-23](../handoff/2026-09-23-backend-fe01-30.md). **Seluruh task BE sisanya (BE-063–149) diimplementasikan atau dicatat evidencenya pada 2026-09-23** — lihat [laporan penyelesaian backend](../handoff/2026-09-23-backend-completion.md) untuk gate, keputusan terbuka (G04, G05, G10, G15, G16, G20) dan batas klaim. Semua tetap menunggu human review; tidak ada klaim Feature Done atau rilis.

## Cara memakai

1. Baca [baseline/sumber](01_BASELINE_DAN_SUMBER.md) dan [aturan eksekusi](02_ATURAN_EKSEKUSI.md).
2. Periksa [traceability](03_TRACEABILITY.md), [kontrak](04_KONTRAK_DATA_HTTP.md), [integrasi FE](05_INTEGRASI_FE.md), serta [gap](06_GAP_DAN_KEPUTUSAN.md).
3. Pilih task paling awal dengan prasyarat dan keputusan yang berlaku sudah terpenuhi. Nomor adalah urutan topologis, bukan sprint atau izin melewati gate.
4. Jalankan TDD per task dan simpan [evidence](07_VERIFIKASI_DAN_EVIDENCE.md); checklist backlog tidak membuktikan runtime.

Rincian turunan: [schema](08_SCHEMA_DAN_CONSTRAINT.md), [field dan validasi](09_FIELD_DAN_VALIDASI.md), [audit/queue/seed](10_AUDIT_QUEUE_SEED.md), [inventaris semua bagian sumber](11_INVENTARIS_SUMBER.md). `catalog.json` adalah katalog dokumentasi untuk pemeriksaan ID/dependency, bukan konfigurasi aplikasi.

Global constraints lengkap ditulis sekali di aturan eksekusi. Tidak ada perubahan `project_doc`, kode aplikasi, dependency, database atau Docker dari penyusunan paket ini. Repository branch untuk paket: `docs/backend-microtasks`; base `8f365a8`.
