## Acceptance criteria

- [ ] **AC-01:** Server invalidates revoked/expired session dan tidak menjalankan aksi sensitif ulang otomatis.
- [ ] **AC-02:** Credential hanya immediate reveal, no-store; back/refresh/cache/log/trace tidak dapat mengungkapnya.
- [ ] **AC-03:** Setup partial progress/reload/complete berjalan melalui approved projection; Team/role/user CRUD denial dan valid re-auth diuji tanpa menunggu Phase9.
- [ ] **AC-04:** Create/reset actual response memenuhi no-store; browser refresh/back dan storage inspection tidak memulihkan password lama.
- [ ] **AC-05:** 401/403/419/422/429 dari route nyata tampil tepat; unsubmitted input tetap terjaga; sensitive action tidak auto replay.
