# BE-156 — Jenis cetakan per kind dan skema ekspor Activity Log

**Phase:** 7–8 · **Parent resmi:** T82A · **Jenis:** FITUR BARU (G26)
**Status implementasi:** IMPLEMENTED 2026-10-12 (menunggu human review dan human security review) · **Hasil pengujian:** PASS lokal (RED `abf7399` → GREEN `40d79c8`; [handoff](../handoff/2026-10-12-activity-log-report.md))

## Tujuan dan sumber

`nscmf_template_versions.template_kind` (`NSCMF_FORM` default | `ACTIVITY_LOG`) dengan satu versi aktif per kind; `nscmf:template:register --kind=activity-log`; tabel `nscmf_activity_log_exports` (snapshot, progres, artefak); kolom `access_audit_events.activity_log_export_id`.

Sumber: [11](../project_doc/11_ERD_Database_Schema.md) §5.3, §36, §41, §44A; [14](../project_doc/14_Environment_Specification.md) §70A; [G26](06_GAP_DAN_KEPUTUSAN.md#g26).

## Acceptance criteria

1. **AC-01:** Kolom `template_kind` NOT NULL default `NSCMF_FORM`, CHECK dua nilai, index `(template_kind, is_active)`.
2. **AC-02:** Mendaftarkan cetakan log tidak menonaktifkan form NSCMF; ekspor NSCMF tetap memakai form.
3. **AC-03:** CHECK format, status, `progress_percent` 0–100, `entry_count` 1–1000.
4. **AC-04:** FK `activity_log_export_id` RESTRICT, nullable.
