# BE-121 — Endpoint publik PDF dengan privasi minimum

**Phase:** 8 · **Parent resmi:** T59 · **Jenis:** IMPLEMENTATION / RECONCILIATION
**Status implementasi:** IMPLEMENTED 2026-09-23 (menunggu human review) · **Hasil pengujian:** PASS lokal: LibreOffice 26.8 + OpenSSL nyata (tests/Feature/Export/PdfSigningAndValidatorTest.php)

## Tujuan dan sumber

GET /ispdfvalid dan POST /ispdfvalid/verify public; exactly one nonzero PDF file <=20,000,000 bytes inclusive (`10 §73`, `12 §73`); private temp→CLEAN→deep verifier; success/failure cleanup; safe min RequestNo/family/issued_at/Organization only for recognized results. Limit counts file bytes, not full multipart request-body bytes.

Sumber: [10_Security_Rules.md](../project_doc/10_Security_Rules.md) §73; [12_API_Contract.md](../project_doc/12_API_Contract.md) §72–75; [16_Testing_Specification.md](../project_doc/16_Testing_Specification.md) §61–64; [20_Deployment_Architecture.md](../project_doc/20_Deployment_Architecture.md) §19–22.
