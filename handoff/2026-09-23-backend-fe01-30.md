## Catatan operasional untuk sesi berikutnya

- **Pest dan Chromium tidak boleh jalan bersamaan.** Keduanya memakai database `nscmf_testing`; user `nscmf` tidak punya hak `CREATE DATABASE`, jadi runtime browser memakai database disposable yang sama dan dijaga `DisposableRuntimeGuard` di dalam proses yang disajikan.
- Playwright memakai `php -S` dengan env eksplisit karena `artisan serve` membuang variabel env yang dibutuhkan guard.
- Baris pertama `.env` sebelumnya berisi artefak `-- Active: ...` dari ekstensi SQL sehingga semua perintah PHP gagal; baris itu dihapus (salinan `.env` disimpan di scratchpad sesi). Tidak ada nilai lain yang diubah.
- Script lokal `storage/framework/testing/pest.sh` dan `stan.sh` adalah kemudahan agent dan git-ignored.
